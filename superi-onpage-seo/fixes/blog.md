# ბლოგი — გასწორებები

Title-ები და description-ები [pages-meta.csv](pages-meta.csv)-შია (ID 36–38).

## 1. `/blog/` გვერდი (ID 36)

ახლა გვერდის სახელი, title, description და H1 „blog“-ია. Website → Blog → „blog“ გვერდის სახელი გახადეთ **ბლოგი**, SEO ჩანართში კი title და description ჩაწერეთ CSV-დან.

## 2. tag-ების ბმულები (ყველა სტატია)

OLED/QLED სტატიის ქვემოთ 8 tag-ის ბმულია („2026 წლის მოდელები“, „HDR ეკრანები“, „mini-LED“...). ისინი `index.php?dispatch=tags.view...`-ზე მიდის, რაც robots.txt-ში დაბლოკილია. Google-ისთვის ეს ბმულები ჩიხია.

**გამოსწორება:** თითოეულ სტატიაში გახსენით **Tags** ჩანართი და tag-ები წაშალეთ. თუ tag-ებს საიტზე სხვაგან არ იყენებთ, Add-ons → Tags შეგიძლიათ საერთოდ გამორთოთ. ნაცვლად ამისა, სტატიის ბოლოს ჩასვით კატეგორიების ბმულები (ქვემოთ, პუნქტი 3).

## 3. OLED vs QLED vs mini-LED (ID 37): ტექსტის გავრცობა

სტატია ახლა 256 სიტყვაა. ქვემოთ მოცემული ბლოკი ჩასვით არსებული ტექსტის ბოლოს, „საბოლოო დასკვნის“ წინ. სტატია ~600 სიტყვამდე გაიზრდება და ტელევიზორების კატეგორიასა და ბრენდებზე ბმულებს მიიღებს.

  <li><strong>50–55 დიუმი (127–139 სმ):</strong> დაახლოებით 1,3–2,1 მეტრიდან — საშუალო ზომის მისაღები ოთახი.</li>

</ul>
<h2>რომელი ტექნოლოგია ვისთვის</h2>
<ul>
  <li><strong>ფილმები ბნელ ოთახში:</strong> OLED — სრული შავი ფერი და ზუსტი კონტრასტი.</li>

  <li><strong>სპორტი და თამაშები:</strong> მიაქციეთ ყურადღება განახლების სიხშირეს (100/120 Hz) და HDMI 2.1 პორტებს.</li>

</ul>
