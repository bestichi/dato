# მთავარი გვერდი — მზა ბლოკები

## 1. Meta description

**სად:** Design → Layouts → Homepage location → პარამეტრები → Meta description. თუ მთავარი გვერდის meta სხვაგან გაქვთ (მაგ. SEO add-on-ში ან ხელით ჩაწერილ JSON-LD-თან ერთად), შეცვალეთ იქ, სადაც ახლაა.

```
ტექნიკისა და ელექტრონიკის ონლაინ მაღაზია: ტელეფონები, ტელევიზორები, ლეპტოპები, მაცივრები. განვადება და უფასო მიწოდება თბილისში 100₾-დან.
```

Title არ იცვლება, ის უკვე კარგია.

## 2. H1 + SEO ტექსტი (ერთი HTML ბლოკი)

**სად:** Design → Layouts → Homepage → გვერდის ბოლოში, footer-ის წინ, ახალი ბლოკი: **HTML block with Smarty support**. Wrapper: არცერთი. ბლოკს სათაური არ სჭირდება.

H1 ერთხელ უნდა იყოს გვერდზე. თუ დიზაინერს H1 ზემოთ ურჩევნია, `<h1>` ზედა ბანერის ქვეშ ცალკე ბლოკად გადაიტანეთ, ტექსტი კი აქ დატოვეთ.

**სტილი** (Design → Themes → CSS-ის რედაქტორი, ან დეველოპერმა ჩასვას). ტექსტი შეიძლება ვიზუალურად მშვიდი იყოს, მაგრამ ხილული უნდა დარჩეს. `display:none` ან ეკრანს გარეთ გატანა არ შეიძლება.

```css

```

## 3. ბლოკების სათაურები H2-ით

ახლა „ფასდაკლებული“, „პოპულარული“, „გაყიდვადი“ და „ჩვენ გირჩევთ“ `div`/`span`-ებია. ეს დეველოპერის დავალებაა: UniTheme2-ის wrapper შაბლონში (`ty-mainbox-title`) `div` შეიცვალოს `h2`-ით. დეტალები: [developer-checklist.md](developer-checklist.md), პუნქტი 2.

## 4. სამუშაო საათები footer-ში

ახლა footer-ში წერია „⏰ სამუშაო საათები: ორშ-კვი 9:00 - 21:00“. კონტაქტის გვერდი და schema კი ამბობს: **ორშაბათი – შაბათი: 10:00 – 21:00**.

ჯერ დაადასტურეთ, რომელია სწორი. შემდეგ footer-ის ბლოკში (Design → Layouts → Footer → კონტაქტის HTML ბლოკი) ჩაწერეთ:

```
⏰ სამუშაო საათები: ორშ–შაბ 10:00–21:00
```

თუ სწორი footer-ის ვერსიაა, მაშინ კონტაქტის გვერდი, მთავარი გვერდის JSON-LD (`hoursAvailable`) და Google Business Profile უნდა შეიცვალოს.
