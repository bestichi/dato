# საიტის მასშტაბის ტექსტური გასწორებები

ყველა ქვემოთ ჩამოთვლილი ცვლილება ადმინ პანელში კეთდება და კოდს არ საჭიროებს. თითოეული ერთ ადგილას იცვლება და ერთბაშად ბევრ გვერდზე ვრცელდება.

## 1. მიწოდების ბლოკი პროდუქტის გვერდზე (ყველა 5 492 პროდუქტი)

**სად:** Add-ons → **AB: Motivation block** → ელემენტი „მიწოდება“.

| ახლა | უნდა იყოს | რატომ |
|---|---|---|
| სტანდარტული მომდევნო **სამუშა** დღეს (უფასო) | სტანდარტული — მომდევნო სამუშაო დღეს (უფასო 100₾-დან) | ბეჭდვითი შეცდომა. პოლიტიკით 100₾-მდე შეკვეთაზე მიწოდება 10₾ ღირს |
| სწრაფი იმავე დღეს(ფასიანი) | სწრაფი — იმავე დღეს (ფასიანი) | ფრჩხილის წინ სივრცე აკლია |
| რეგიონი 3-5 სამუშაო დღე (ფასიანი) | რეგიონები — 3–5 სამუშაო დღე (ფასიანი) | |
| ბმული „მიწოდება“ → `https://superi.ge/page22/?action=preview` | `https://superi.ge/delivery/` | ახლა ყველა პროდუქტის გვერდი გვერდის preview ვერსიაზე მიუთითებს, რომელიც robots.txt-ით დაბლოკილია |

იმავე ბლოკის „გადახდა“ ელემენტში ჩაწერეთ: `განვადება (საქართველოს ბანკი, კრედო ბანკი, თიბისი ბანკი)`. ახლა მძიმის შემდეგ სივრცე აკლია და „ბანკი“ მხოლოდ ერთხელ წერია.

ასევე შეამოწმეთ, სხვა motivation ელემენტებშიც ხომ არ არის `?action=preview` ბმულები.

## 5. ფილტრები (Products → Features)

ფილტრების სახელებსა და მნიშვნელობებში 28 შეცდომაა: ბეჭდვითი შეცდომები, კირილიცის ასოები, დუბლიკატები და არასწორი მნიშვნელობები, მაგალითად „ოპერატიული მეხსიერების ტიპი: უფასო მიწოდება“. სრული სია: [filters-cleanup.csv](filters-cleanup.csv).

დუბლიკატების გაერთიანებისას (მაგ. „12GB“ და „12 GB“) ჯერ პროდუქტები გადაიტანეთ სწორ მნიშვნელობაზე და მხოლოდ შემდეგ წაშალეთ ზედმეტი. სხვაგვარად ის პროდუქტები ფილტრიდან გაქრება.
