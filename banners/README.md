# superi.ge — მთავარი ბანერის ვარიანტები

ზომა: **3200×800** (როგორც საიტის ახლანდელი ბანერი `superi-desktop-banner-optimized.webp`).
საიტზე ასატვირთი ფაილები: `out/v1.webp` … `out/v6.webp` (~110–130 KB). PNG ვერსიები იქვეა.

| ვარიანტი | სტილი | სათაური |
|---|---|---|
| `v1` | ღია, ბრენდის მწვანე, წითელი ბეჯი | სუპერ ფასები |
| `v2` | მუქი, ნათება, დიდი -50% | მეგა ფასდაკლება |
| `v3` | ფერადი მწვანე, პროდუქტის ბარათები | ფასები დაეცა! |
| `v4` | წითელი, კლასიკური ფასდაკლება | საუკეთესო ფასები |
| `v5` | **მოდერნი:** მუქი მწვანე, დიდი ბაცი %, მთავრული, პროდუქტების ჯგუფი | ᲤᲐᲡᲔᲑᲘ ᲓᲐᲔᲪᲐ |
| `v6` | იგივე, ჰედერის ფერის მუქ ფონზე | ᲤᲐᲡᲔᲑᲘ ᲓᲐᲔᲪᲐ |

მთავარი ტექსტი და პროდუქტები ჩარჩოს შიგნით, კიდიდან 150px-ზე დგას, ამიტომ ვიწრო ეკრანზე
ბანერის კიდეები რომ მოიჭრას (`background-size: cover`), ტექსტი მაინც სრულად გამოჩნდება.

## საიტზე ატვირთვა

ადმინპანელი → Marketing → Banners → მთავარი ბანერი (ახლანდელი, ID 10067) → ფონის სურათი
(background image) → ატვირთე არჩეული `vN.webp`.

## ტექსტის შეცვლა და თავიდან გენერაცია

ტექსტი, ფერები და პროდუქტების ადგილი `vN.html` ფაილებშია. გენერაციისთვის საჭიროა Node + Playwright:

```sh
NODE_PATH=$(npm root -g) node render.mjs          # ყველა ვარიანტი → out/vN.png
NODE_PATH=$(npm root -g) node render.mjs v2       # მხოლოდ ერთი
python3 -c "from PIL import Image; Image.open('out/v2.png').convert('RGB').save('out/v2.webp', quality=86, method=6)"
```

საიტზე როგორ გამოჩნდება (ცოცხალ superi.ge-ზე მხოლოდ მთავარ ბანერს ცვლის, სკრინშოტი → `out/site-vN.png`):

```sh
NODE_PATH=$(npm root -g) node preview.mjs
```

შრიფტები: Noto Sans Georgian და Montserrat (OFL ლიცენზია), `assets/fonts`-შია.
პროდუქტების სურათები superi.ge-დანაა აღებული. v1, v2 და v4-ზე კატეგორიების ბანერების სურათებია.
v3-ზე სხვა პროდუქტებია (მაცივარი, LEGO, ყავის აპარატი, სკუტერი), რომ ქვემოთ კატეგორიების ბარათებს არ გაიმეოროს.
თეთრი ფონი `cutout.py`-თ მოიჭრა:

```sh
python3 cutout.py photo.jpg assets/name.png              # თეთრი/ღია ფონი → გამჭვირვალე PNG
python3 cutout.py scooter.webp assets/scooter.png --holes 400   # ჩაკეტილი ფონის ადგილებიც
```
