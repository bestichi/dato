# 5.1 გაზის გამათბობლები ფართის მიხედვით — 4 ახალი გვერდი

**რატომ:** Search Console (ივლისი–ოქტომბერი 2026): ფართის მოთხოვნებს („გაზის გამათბობელი 120 კვადრატი“ და ა.შ.) ჯამში ~9 000 ჩვენება აქვს,
პოზიცია 4–9, CTR 1.5–3.4%. ახლა მათ ზოგადი კატეგორია პასუხობს. ცალკე გვერდი ზუსტად ამ მოთხოვნისთვის — ჩვეულებრივ უკეთ რანჟირდება.
გათბობის სეზონი ახლა იწყება — Google-ს გვერდების ასაღებად 2–4 კვირა სჭირდება, ამიტომ ეს ახლა უნდა გაკეთდეს.

## როგორ (ადმინკა)

1. **პროდუქტები → კატეგორიები → დამატება.** მშობელი კატეგორია: **გაზის გამათბობლები**.
2. შეავსეთ: სახელი, აღწერა (ქვემოთ მოცემული ტექსტი, რედაქტორის კოდის რეჟიმში), SEO სახელი (URL), გვერდის სათაური (title), მეტა-აღწერა.
3. **პროდუქტების მიბმა:** პროდუქტების სიაში მონიშნეთ ქვემოთ ჩამოთვლილი → „არჩეულის რედაქტირება“ → კატეგორიებში **დაამატეთ** ახალი კატეგორია
   (მთავარი კატეგორია „გაზის გამათბობლები“ არ წაშალოთ). ერთი პროდუქტი შეიძლება ორ გვერდზეც იყოს (მაგ. 80–100 მ²).
4. **ბმულები მშობელ კატეგორიაზე:** „გაზის გამათბობლები“-ს აღწერაში, სექციაში „გაზის გამათბობელი ფართობის მიხედვით“, ფართის თითოეული სათაური გახადეთ ბმული შესაბამის ახალ გვერდზე.
5. sitemap-ის გენერირება → Search Console → URL Inspection → „Request indexing“ 4 ახალ მისამართზე.

რიგითობა მოთხოვნების მოცულობით: ჯერ 100–130, შემდეგ 70–80, 40–60, ბოლოს 30-მდე.
