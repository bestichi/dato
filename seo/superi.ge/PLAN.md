## 1) მთავარი გვერდი — H1 + SEO ტექსტი

**პრობლემა:** `https://superi.ge/` — `<h1>` = 0, `<h2>` = 0. ეს საიტის ყველაზე ძლიერი გვერდია,
მაგრამ Google-ს არ ეუბნება, რაზეა ის („ტექნიკის ონლაინ მაღაზია“, „ელექტრონიკა“ და ა.შ.).

**რა უნდა გაკეთდეს (≈20 წთ, CS-Cart ადმინკა):**

1. `დიზაინი → განლაგება (Design → Layouts)` → ჩანართი **მთავარი გვერდი (Homepage)**.
2. ბოლო კონტეინერში (ფუტერის წინ) → **Add grid** → **Add block** → **HTML ბლოკი**.
3. ჩასვით [`01-homepage-seo-block.html`](01-homepage-seo-block.html)-ის შიგთავსი.
   თუ რედაქტორი ვიზუალურია (WYSIWYG), გადართეთ **კოდის (Source / `<>`)** რეჟიმზე, თორემ `<h1>` შეიძლება წაიშალოს.
4. ბლოკის სათაური დატოვეთ ცარიელი (ან ჩართეთ „სათაურის დამალვა“), რომ მეორე სათაური არ გამოჩნდეს.
5. შეინახეთ, გაასუფთავეთ ქეში (`ადმინკა → ქეშის გასუფთავება` + Cloudflare → Purge).

**შემოწმება:** მითხარით „1 მზადაა“ — გადავამოწმებ, რომ გვერდზე ზუსტად ერთი H1-ია და ტექსტი Google-ისთვის ჩანს.
