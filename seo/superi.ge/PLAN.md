## 1) მთავარი გვერდი — SEO ტექსტი (არჩევითი)

მფლობელის გადაწყვეტილებით H1 არ ემატება. მზა ტექსტური ბლოკი H1-ის გარეშე:
[`01-homepage-seo-block.html`](01-homepage-seo-block.html) — ჩასმა: `დიზაინი → განლაგება → მთავარი გვერდი → HTML ბლოკი`
(რედაქტორი კოდის რეჟიმში), ფუტერის წინ.

## 2) სიჩქარე მობილურზე — დავალება დეველოპერისთვის

გაზომვა: Lighthouse, მობილური, 2026-10-12 (აშშ-დან — საქართველოდან რიცხვები შეიძლება უკეთესი იყოს).

| გვერდი | Performance | LCP | TBT | DOM ელემენტები |
|--------|-------------|-----|-----|----------------|
| მთავარი | 57 | 4.1 წმ | 1 020 მწმ | 1 708 |
| კატეგორია (ტელევიზორები) | 70 | 3.2 წმ | 810 მწმ | 3 785 |
| პროდუქტი | 76 | 3.1 წმ | 520 მწმ | 1 867 |

მიზანი: LCP < 2.5 წმ, TBT < 200 მწმ (Core Web Vitals „კარგი“ ზონა).

**2.1 HTML-ის ქეშირება სტუმრებისთვის (ყველაზე დიდი ეფექტი).**
ყველა გვერდი ყოველ ჯერზე თავიდან გენერირდება: `cache-control: no-store`, `cf-cache-status: DYNAMIC`,
სერვერის პასუხი 0.6–1.0 წმ. ჩართეთ full-page cache არაავტორიზებული სტუმრებისთვის (CS-Cart-ის
full-page cache ადონი ან LiteSpeed-ის ქეში — სერვერი LiteSpeed-ზეა) + Redis CS-Cart-ის ქეშისთვის.
მიზანი: სერვერის პასუხი < 300 მწმ.

**2.2 რენდერის ბლოკირება `<head>`-ში.**
- `js/addons/gdpr/lib/klaro.js` (cookie-ბანერი) იტვირთება სინქრონულად → `defer`.
- `standalone.css` — 197 KB, მთავარ გვერდზე 93% გამოუყენებელია → კრიტიკული CSS inline, დანარჩენი ასინქრონულად.

**2.3 JavaScript (TBT 1.0 წმ).**
`scripts-*.js` — 297 KB, აქედან 191 KB გამოუყენებელი; + jQuery. მთავარი ნაკადის მუშაობა 6.5 წმ.
გამორთეთ ადონები, რომლებიც რეალურად არ გამოიყენება (თითოეული საერთო JS/CSS ბანდლში ემატება).

**2.4 DOM-ის ზომა.**
ყოველ გვერდზე სრული მეგა-მენიუ (100+ ბმული) HTML-შია; კატეგორიაზე 3 785 ელემენტი.
შეამოწმეთ თემის (UniTheme2) პარამეტრი მენიუს AJAX-ით/ზარმაცად ჩატვირთვისთვის.

**2.5 სურათები და ფონტები.**
- მთავარი გვერდის მცირე ბანერები (`banners/all/27/*.webp`) ჩვენებულ ზომაზე დიდია → დაზოგვა ≈130 KB.
- იკონ-ფონტი `uni2-icons.ttf` → WOFF2.

**შემოწმება:** შესრულების შემდეგ ხელახლა გავზომავ იგივე 3 გვერდს და შევადარებ ამ ცხრილს.
