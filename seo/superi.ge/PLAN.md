## 1) მთავარი გვერდი — SEO ტექსტი (არჩევითი)

მფლობელის გადაწყვეტილებით H1 არ ემატება. მზა ტექსტური ბლოკი H1-ის გარეშე:
[`01-homepage-seo-block.html`](01-homepage-seo-block.html) — ჩასმა: `დიზაინი → განლაგება → მთავარი გვერდი → HTML ბლოკი`
(რედაქტორი კოდის რეჟიმში), ფუტერის წინ.

## 2) სიჩქარე მობილურზე — ✅ კარგ მდგომარეობაშია

მფლობელის გაზომვა (PageSpeed Insights, რეალური მომხმარებლები, 28 დღე, მობილური):
LCP 1.3 წმ, FCP 1.2 წმ, CLS 0, TTFB 0.8 წმ — ყველა მწვანე. Google რანჟირებისთვის სწორედ ამ მონაცემებს იყენებს.
TTFB 0.8 წმ „კარგის“ ზღვარზეა, ამიტომ ქვემოთ 2.1 (ქეშირება) სასურველია, მაგრამ აღარ არის სასწრაფო.
დანარჩენი პუნქტები არჩევითია.

### არჩევითი: დავალება დეველოპერისთვის

მიზანი: LCP < 2.5 წმ, TBT < 200 მწმ (Core Web Vitals „კარგი“ ზონა).

**2.1 HTML-ის ქეშირება სტუმრებისთვის (ყველაზე დიდი ეფექტი).**
ყველა გვერდი ყოველ ჯერზე თავიდან გენერირდება: `cache-control: no-store`, `cf-cache-status: DYNAMIC`,
სერვერის პასუხი 0.6–1.0 წმ. ჩართეთ full-page cache არაავტორიზებული სტუმრებისთვის (CS-Cart-ის
full-page cache ადონი ან LiteSpeed-ის ქეში — სერვერი LiteSpeed-ზეა) + Redis CS-Cart-ის ქეშისთვის.
მიზანი: სერვერის პასუხი < 300 მწმ.

**2.2 რენდერის ბლოკირება `<head>`-ში.**
- `js/addons/gdpr/lib/klaro.js` (cookie-ბანერი) იტვირთება სინქრონულად → `defer`.
- `standalone.css` — 197 KB, მთავარ გვერდზე 93% გამოუყენებელია → კრიტიკული CSS inline, დანარჩენი ასინქრონულად.

**2.3 JavaScript (TBT 1.0 წმ).**
`scripts-*.js` — 297 KB, აქედან 191 KB გამოუყენებელი; + jQuery. მთავარი ნაკადის მუშაობა 6.5 წმ.
გამორთეთ ადონები, რომლებიც რეალურად არ გამოიყენება (თითოეული საერთო JS/CSS ბანდლში ემატება).

**2.4 DOM-ის ზომა.**
ყოველ გვერდზე სრული მეგა-მენიუ (100+ ბმული) HTML-შია; კატეგორიაზე 3 785 ელემენტი.
შეამოწმეთ თემის (UniTheme2) პარამეტრი მენიუს AJAX-ით/ზარმაცად ჩატვირთვისთვის.

**2.5 სურათები და ფონტები.**
- მთავარი გვერდის მცირე ბანერები (`banners/all/27/*.webp`) ჩვენებულ ზომაზე დიდია → დაზოგვა ≈130 KB.
- იკონ-ფონტი `uni2-icons.ttf` → WOFF2.

**შემოწმება:** შესრულების შემდეგ ხელახლა გავზომავ იგივე 3 გვერდს და შევადარებ ამ ცხრილს.

## 3) Google Merchant Center — უფასო ჩვენება Google Shopping-ში

**რატომ:** Merchant Center-ში ატვირთული პროდუქტები შეიძლება უფასოდ გამოჩნდეს Google-ის „Shopping“ ჩანართსა და ძიების შედეგებში.
საქართველოს ხელმისაწვდომობა დაუზუსტებელია: Google-ის ერთ ცხრილში საქართველო (GEL) ჩამოთვლილია, უფასო ჩვენებების სიაში კი — არა.
ამიტომ პირველი ნაბიჯი შემოწმებაა.

**ნაბიჯი 1 — შემოწმება (15 წთ, უფასო):**
1. merchants.google.com → ანგარიშის შექმნა: ბიზნესი „შპს ბესთ სოლუშენ 2022“, საიტი `https://superi.ge/`, ქვეყანა საქართველო.
2. საიტის დადასტურება (ყველაზე მარტივია, თუ Search Console უკვე დადასტურებულია იმავე Google ანგარიშით).
3. პროგრამების / Marketing methods განყოფილებაში შეამოწმეთ, არის თუ არა **Free listings / Product listings** ხელმისაწვდომი.
   - თუ **არის** → ნაბიჯი 2.
   - თუ **არ არის** → ვტოვებთ და გადავდივართ მე-4 პუნქტზე.

**ნაბიჯი 2 — პროდუქტების ფიდი (დეველოპერი, ~1 დღე):**
- CS-Cart-ის Data feeds / Google export ადონით XML ფიდი: `id`, `title`, `description`, `link`, `image_link`,
  `price` (GEL), `availability`, `brand`, `condition=new`.
- GTIN (შტრიხკოდი) — 120-დან 0 პროდუქტს აქვს. თუ შტრიხკოდები ბაზაშია, დაემატოს; თუ არა — `brand` + `mpn` (მოდელის კოდი).
- Merchant Center-ში ფიდის URL — ყოველდღიური ავტომატური განახლებით.
- მიწოდება და დაბრუნება Merchant Center-ის პარამეტრებში: თბილისი — უფასო 100 ₾-დან, ქვემოთ 10 ₾, 1 სამუშაო დღე;
  რეგიონები — 3–5 სამუშაო დღე; დაბრუნება — 14 დღე.
