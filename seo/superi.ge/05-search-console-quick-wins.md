# 5.1 Search Console — სწრაფი მოგება სათაურებით (ტესტი)

წყარო: Search Console, 2026-07-12 – 2026-10-12, არაბრენდული მოთხოვნები.

## რა აჩვენა მონაცემებმა

**ხალხი მხოლობითში ეძებს, საიტი კი მრავლობითშია დაწერილი.** ყველა კატეგორიის სათაური მრავლობითშია
(„გაზქურები — საუკეთესო ფასები“). 27 წყვილიდან 19-ში საიტი მრავლობით ფორმაზე უკეთ რანჟირდება,

**გაზის გამათბობლები ფართით:** „გაზის გამათბობელი 120 / 150 / 60 / 100 კვადრატი“ — პოზიცია 4–5.5, მაგრამ CTR 1.5–3.2%,
ანუ ორჯერ ნაკლები, ვიდრე საიტს იმავე პოზიციაზე ჩვეულებრივ აქვს (4.2–8.4%). ძიების შედეგში ჩანს ზოგადი „საუკეთესო ფასები“ —
ფართი, რასაც კაცი ეძებს, არ ჩანს.

## როგორ გავზომავთ

- დანარჩენი კატეგორიები უცვლელი რჩება — ისინი შედარების ჯგუფია.
- 3–4 კვირაში: Search Console → Performance → **Compare** (ბოლო 28 დღე vs წინა 28 დღე) → ექსპორტი.
- ვადარებ: მხოლობითი მოთხოვნების პოზიციას და „კვადრატი“-ს მოთხოვნების CTR-ს.
- თუ მუშაობს — იგივე წესი (მხოლობითი ფორმა სათაურის დასაწყისში) დანარჩენ კატეგორიებზე.

## შემდეგი კანდიდატი (ჯერ არ ვაკეთებთ)

**მობილურები — 57 000 ჩვენება, პოზიცია 8.4.** ერთი მოდელი 3–5 ცალკე გვერდადაა (ფერი/მეხსიერება) და ისინი ერთმანეთს ეჯიბრებიან:
მაგ. POCO X8 Pro — 5 URL, POCO F7 — 4, Google Pixel 9 — 4. საიტი CS-Cart-ის ვარიაციებს „ცალკე პროდუქტებად“ იყენებს
(თითოეულს საკუთარი canonical). გაერთიანება სავარაუდოდ დაეხმარება, მაგრამ CS-Cart-ის ქცევა canonical-ზე დასადასტურებელია —
ჯერ ერთ მოდელზე ტესტი.

## სხვა შენიშვნები

- 50 გადარქმეული URL (`/category-NN/`, `/ag-10m/` …) სწორად გადამისამართდება (301 → 200). წესი: სეზონში რანჟირებადი გვერდების URL-ს აღარ ვცვლით.
- 4 ძველი URL აბრუნებს 404-ს (21 კლიკი 3 თვეში) — უმნიშვნელოა.
