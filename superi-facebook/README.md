## 1. აუდიტი: რა უნდა გასწორდეს

> **შენიშვნა:** facebook.com ჩემი სამუშაო გარემოდან დაბლოკილია, ამიტომ გვერდს პირდაპირ ვერ ვხედავ. აუდიტი გაკეთდა superi.ge-ის მონაცემებით და FB გვერდის სტანდარტული ჩეკლისტით. თუ გვერდის სქრინშოტებს გამომიგზავნი (კომპიუტერიდან და მობილურიდან), თითოეულ პუნქტზე ზუსტ შენიშვნას მოგწერ.

### 🔴 კრიტიკული

1. **ლოგო Shopify-ის ლოგოს ჰგავს.** მწვანე ჩანთა „S" ასოთი თითქმის ერთი-ერთში Shopify-ის სავაჭრო ნიშანია. ამას ორი პრობლემა მოაქვს:
   - იურიდიული რისკი: სავაჭრო ნიშნის დარღვევაზე შესაძლოა მოვიდეს საჩივარი, ხოლო Meta-მ შესაძლოა შეზღუდოს რეკლამა ან გვერდი.
   - დაბნეულობა: მომხმარებელს შეიძლება ეგონოს, რომ ეს Shopify-ის პლატფორმაა და არა ქართული ბრენდი.

   **გადაწყვეტილება:** კლიენტმა არჩია არსებული ლოგოს დატოვება. ახალი „S."-ის შეთავაზება `05-logo/`-შია, თუ მომავალში დაგჭირდება.
2. **საიტზე Meta Pixel არ არის.** Google Analytics დაყენებულია, Facebook Pixel კი არა. ამის გამო FB/Instagram რეკლამიდან გაყიდვებს ვერ გავზომავთ და ვერც რეტარგეტინგს გავაკეთებთ, ანუ ვერ ვაჩვენებთ რეკლამას მათ, ვინც საიტზე პროდუქტი ნახა. დომენი (`facebook-domain-verification`) არც ის არის ვერიფიცირებული.
3. **superi.ge-ის ლინკის პრევიუ FB-ზე ცუდად ჩანს.** `og:image` არის 250×62-იანი ლოგო, ამიტომ ლინკის გაზიარებისას პატარა, ბუნდოვანი სურათი გამოჩნდება. მოვამზადე `04-website/og-image-1200x630.jpg`. საიტის დეველოპერმა `<head>`-ში ეს უნდა ჩასვას:
   ```html
   <meta property="og:image" content="https://superi.ge/og-image-1200x630.jpg">
   <meta property="og:image:width" content="1200">
   <meta property="og:image:height" content="630">
   ```

### 🟠 მნიშვნელოვანი

4. **„აქციების" გვერდი ცარიელია.** იქ წერია „ამჟამად მოქმედი აქციები არ არის", მთავარ ბანერზე კი „−50%-მდე". FB-დან მოსული მომხმარებელი დაიბნევა. ბანერი მიაბით „ფასდაკლებულის" გვერდს (`superi.ge/index.php?dispatch=products.on_sale`) ან შეავსეთ აქციების გვერდი.
5. **ლოგოს მხოლოდ ერთი ვერსია აქვს.** ის თეთრი ტექსტია გამჭვირვალე ფონზე და თეთრ ფონზე არ იკითხება. საჭიროა მუქი და ღია ვერსია, კვადრატული ვერსია და ვექტორი (SVG).
6. **Instagram არსად ჩანს.** თუ ანგარიში გაქვთ, დააკავშირეთ FB გვერდთან, რომ ერთი პოსტი ორივეგან გამოქვეყნდეს. ლინკი საიტის ფუტერშიც დაამატეთ.

## 4. შემდეგი ნაბიჯები

1. **ატვირთე** ქოვერი `00-upload-to-facebook/`-დან.
2. **საიტის მობილურ ვერსიაზე** მთავარი ბანერი მოჭრილია (სათაურიდან მხოლოდ ბოლო ასოები ჩანს). საჭიროა ბანერის ცალკე მობილური ვერსია.
3. **Meta Pixel + დომენის ვერიფიკაცია** საიტზე. CS-Cart-ს ამისთვის მზა მოდული აქვს, ან დეველოპერი ჩასვამს.
4. **og:image** ჩასვი საიტზე (კოდი ზემოთაა).
5. **გამომიგზავნე** გვერდის სქრინშოტები და Insights (ასაკი, ქალაქი, აქტიური საათები). ამის მიხედვით ზუსტ აუდიტს გავაკეთებ და მე-2 კვირის გეგმას შევადგენ.

**ავტომატური დაპოსტვა:** ამ გარემოდან Facebook-ზე პირდაპირ ვერ ვპოსტავ. თუ გინდა, რომ პოსტები ავტომატურად დაიგეგმოს, საჭიროა Meta App, Page Access Token და ამ გარემოს ქსელურ პოლიტიკაში graph.facebook.com-ის დაშვება. ამის შემდეგ სკრიპტს ავაწყობ.

## სურათების ხელახლა გენერაცია

საჭიროა Node.js, Playwright (Chromium) და Python 3.

```bash
cd superi-facebook/source
python3 gen_posts.py                      # posts.json → posts/*.html
node render.js "$(cat jobs.json)"         # → out/posts/*.png (1080×1350)
```

ლოგოს SVG-ების თავიდან აწყობა (საჭიროა `pip install fonttools brotli`):

```bash
python3 make_logo.py out/logo                                    # → SVG
node render_svg.js '[{"svg":"'$PWD'/out/logo/superi-badge.svg","out":"'$PWD'/out/badge.png","w":1000}]'
```
